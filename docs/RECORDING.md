# Screen recording script (2–3 minutes, iPhone 16)

Privacy first: Roomy set to **Limited Access** with only a throwaway test album selected (or a test phone),
test contacts only, Do Not Disturb on. Start the recording from Control Center.

| Time | Show | Say (optional captions) |
|---|---|---|
| 0:00 | Fresh install → onboarding with Roomy the robin | "On-device only. Nothing is deleted without review." |
| 0:10 | Allow Photos (Limited → pick the test album), allow Contacts | Permissions are asked one at a time |
| 0:25 | Dashboard: ring fills while scanning, Roomy thinking, tiles fill in | The scan streams; the UI never waits |
| 0:45 | Similar Photos: a group with Best badge and "Exact duplicate" / "Taken 2s apart" | Every group says why |
| 1:00 | Compare → swipe, "Remove this one"; back → "Select all extras" | Nothing is pre-selected |
| 1:15 | Screenshots grid → Select a month; Large Videos → play one, select it | |
| 1:30 | Duplicate Contacts → merge preview with "from other card" tags → Merge 2 cards | A backup is written first |
| 1:45 | Review sheet → remove one item → red button → confirmation → iOS prompt → Delete | One delete path, two confirmations |
| 2:05 | Result: "Moved N items", dashed ring "not freed yet", steps for Recently Deleted | Removed is not freed |
| 2:20 | Open Photos → Recently Deleted → Delete All → back to Roomy | |
| 2:35 | "Free space went up" with the measured number, Roomy celebrating | Measured, not estimated |
| 2:45 | Settings → Contact backups | Restore path |

Tips: portrait only; stay on each screen long enough to read; blur anything personal before sharing.
