# Screen recording script (2–3 minutes, iPhone 16)

Privacy first: Roomy set to **Limited Access** with only a throwaway test album selected (or a test phone),
test contacts only, Do Not Disturb on. Start the recording from Control Center. A simulator run of the same
flow (dark mode, iPhone 18 Pro, iOS 27) is a good reference for pacing.

| Time | Show | Say (optional captions) |
|---|---|---|
| 0:00 | Fresh install → Welcome: the storage bar fills, turns red and shakes, Roomy lands and it sweeps low | "On-device only. Nothing is deleted without review." |
| 0:10 | How Roomy cleans up → Permissions: allow Photos (Limited → the test album) and Contacts | Continue waits for Photos |
| 0:25 | Dashboard: first scan, tiles fill with real items, bottom capsule shows the scan | The scan streams; the UI never waits |
| 0:45 | Similar Photos: a group with the Best badge and "Exact duplicate" / "Taken 2s apart" | Every group says why |
| 1:00 | Compare → page, "Make keeper" / "Remove this one"; back → "Select all extras" | Nothing is pre-selected |
| 1:15 | Screenshots → select a few; Large Videos → play one in the sheet, Add to Review | |
| 1:30 | Duplicate Contacts → merge preview with "from other card" tags → Merge | Merged, not deleted; backup first |
| 1:45 | Review sheet → the list, the red glass Delete → confirmation → iOS prompt → Delete | One delete path, two confirmations |
| 2:05 | Result: "Moved N items", amber marker "in Recently Deleted", Finish in Photos steps | Removed is not freed |
| 2:20 | Open Photos → Recently Deleted → Delete All → back to Roomy | |
| 2:35 | "Free space went up": the marker turns green, "now free", Roomy celebrating | Measured, not estimated |
| 2:45 | Settings → Appearance (System / Light / Dark) and Contact backups | Restore path |

Tips: portrait only; stay on each screen long enough to read; blur anything personal before sharing.
